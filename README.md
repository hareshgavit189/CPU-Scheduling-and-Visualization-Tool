# CPU Scheduling and Visualization Tool

## 📌 Project Description
This project is a CPU Scheduling simulator developed using C and Shell Script. It helps students understand scheduling algorithms through visualization.

## ⚙️ Technologies Used
- C Programming
- Shell Script
- GitHub

## 🧠 Algorithms Implemented
- FCFS
- SJF
- Round Robin

## ▶️ How to Run

Compile:
gcc cpu_scheduling.c -o cpu

Run:
./cpu

OR

sh run.sh

## 📊 Features
- Calculates Waiting Time & Turnaround Time
- Displays Gantt Chart
- Simple CLI-based tool

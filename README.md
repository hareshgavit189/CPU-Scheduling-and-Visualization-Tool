# CPU Scheduling and Visualization Tool

## 📌 Project Description
This project is a CPU Scheduling simulator developed using C and Shell Script. It helps students understand different CPU scheduling algorithms through practical visualization.

## 🎯 Objectives
- To understand CPU scheduling algorithms
- To visualize process execution
- To calculate performance metrics

## ⚙️ Technologies Used
- C Programming Language
- Shell Scripting
- GitHub

## 🧠 Algorithms Implemented
- First Come First Serve (FCFS)
- Shortest Job Next (SJN)
- Round Robin
- Priority Scheduling

## 📊 Features
- Accepts process details (Arrival Time & Burst Time)
- Calculates:
  - Waiting Time
  - Turnaround Time
  - Throughput
- Displays Gantt Chart (text-based visualization)
